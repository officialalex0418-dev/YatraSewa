# YatraSewa - Documentation Overview

## Introduction
YatraSewa is a production-ready, enterprise-grade transportation management and ticket booking platform designed for scalability and exceptional user experience. It simplifies the journey for travelers across Nepal while providing robust management tools for bus operators.

## Vision
To become the most reliable and user-friendly digital transportation ecosystem in the region, supporting millions of bookings with a modern SaaS architecture.

## Project Structure
The project is built as a Next.js Fullstack application (App Router) with the following core directories:
- `src/app`: Routes and API handlers.
- `src/db`: Database schema (Drizzle ORM) and seeding logic.
- `src/components`: Reusable UI components (shadcn-inspired).
- `src/lib`: Shared utilities and authentication logic.

## Core Entities
- **Users**: Admin, Company, Customer roles.
- **Fleet**: Buses, Routes, and Trips.
- **Transactions**: Bookings, Wallet, and Loyalty Points.
