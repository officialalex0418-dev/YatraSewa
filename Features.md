# Features List

## ✅ Completed Features
- **Modern Landing Page**: High-conversion hero section with quick search.
- **Search Engine**: Filterable bus search based on origin, destination, and date.
- **Visual Seat Selector**: Interactive bus layout for picking seats.
- **JWT Auth**: Secure login/register with HttpOnly cookie persistence.
- **RBAC**: Automatic redirection based on user roles (Admin/Company/Customer).
- **Yatra Points**: Automated calculation and awarding of 10% loyalty points.
- **Yatra Wallet**: Balance tracking and point transaction history.
- **PDF Generation**: Downloadable tickets with detailed travel info.
- **QR Code Integration**: Unique QR codes for every booking for easy verification.
- **Admin Dashboard**: Overview of platform users and bookings.
- **Company Fleet Mgmt**: CRUD operations for bus management.

## 🚀 Upcoming Features
- **Live Seat Locking**: Socket.io integration to prevent double booking.
- **Real-time Notifications**: Email/SMS updates via Resend and Sparrow SMS.
- **Coupon System**: Dynamic discount codes for festivals and referrals.
- **Membership Tiers**: Silver, Gold, Platinum, Diamond benefits.
- **Advanced Analytics**: Recharts-based revenue and booking charts.
