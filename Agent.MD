# Agent & User Role Definitions

## 1. Super Admin
- **Access**: Full platform control.
- **Responsibilities**: 
  - Approve/Reject new bus companies.
  - Monitor global booking trends and revenue.
  - Manage all platform users and resolve disputes.
  - Configure loyalty point percentages and system settings.

## 2. Company (Bus Operator)
- **Access**: Company Dashboard.
- **Responsibilities**:
  - Manage fleet (Buses, registration numbers).
  - Define routes and schedules.
  - Create trips with pricing and departure times.
  - View company-specific revenue reports.

## 3. Manager
- **Access**: Managed company dashboard.
- **Responsibilities**: 
  - Oversee daily operations of a specific company.
  - Manage staff (Drivers, Conductors, Counter staff).

## 4. Driver / Conductor
- **Access**: Mobile-optimized trip views.
- **Responsibilities**:
  - View passenger manifest for their assigned trips.
  - Verify passenger tickets via QR code scanning.

## 5. Customer
- **Access**: Public portal and personal dashboard.
- **Responsibilities**:
  - Search and book tickets.
  - Manage loyalty points and wallet balance.
  - View and download past tickets.
